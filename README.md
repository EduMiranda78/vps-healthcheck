# vps-healthcheck

Ferramenta profissional de auditoria, monitoramento e inventário para servidores VPS Linux.

Projeto escrito em Bash com arquitetura modular, focado em Debian 12 e Ubuntu 22.04+.

---

## Objetivo

O vps-healthcheck reúne informações importantes de um servidor Linux em uma única execução:

- sistema operacional
- CPU
- memória
- disco
- rede
- serviços
- atualizações
- segurança
- Docker
- Nginx
- bancos de dados
- aplicações Python
- ferramentas de IA

A saída pode ser gerada em:

- terminal
- TXT
- JSON
- HTML
